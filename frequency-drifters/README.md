# Frequency Drifters

A zero-gravity musical racing game built with Three.js and Tone.js.

## How to Play

**Controls:**
- **WASD / Arrow Keys** - Move your ship
- **SHIFT** - Drift (build combos for score multipliers)
- **R** - Respawn

**Objective:**
- Race through the asteroid field to the finish line (500m)
- Collect musical note orbs (C, D, E, G, A) to build melodies
- Complete triads (C-E-G) for bonus points
- Avoid asteroids - 3 hits and you're out!

**Scoring:**
- Time: Faster finish = more points
- Notes: 100 points each
- Triads: 500 points bonus
- Drift Combos: Multiplier for score

## Features

- 🎵 Musical note collection with Tone.js synths
- 🚀 Zero-G physics with momentum
- 💫 Bloom post-processing effects
- 🎮 Drift mechanics with combo system
- 🌌 Deep space aesthetic

## Tech Stack

- Three.js r183 (3D rendering)
- Tone.js 15.1.22 (Audio synthesis)
- Single HTML file - no build required

## Play Online

Open `index.html` in a modern browser.
